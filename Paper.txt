
# Q1 Journal Master Blueprint: PI-KINN

**Working Title:** *Fourier-Slice Kirchhoff Networks: Edge-Deployable, Stateful ODEs for Computed Tomography Reconstruction*

## 1. The Core Pitch (For your Abstract & Introduction)
**The Problem:** State-of-the-art (SOTA) unrolled iterative networks for CT reconstruction (e.g., Transformers, deep CNNs) suffer from three fatal flaws:
1. They rely on computationally prohibitive $O(N^3)$ ray-tracing physics, preventing deployment on Edge-AI devices.
2. They utilize unbounded feature extractors, leading to gradient instability and requiring massive parameter counts to memorize physics.
3. They treat unrolled cascades as independent blocks, "forgetting" deep feature representations between iterations.

**The Solution:** We introduce the **Physics-Informed Kirchhoff-Inspired Neural Network (PI-KINN)**. By mapping the forward physics entirely into the Fourier domain via the Differentiable Fourier-Slice Theorem, we reduce complexity to $O(N^2 \log N)$. To stabilize the learning and mitigate Fourier gridding artifacts, we embed the physical gradients into a stateful Kirchhoff Neural Cell modeled as a Zero-Order-Hold RC circuit. This ODE mathematically acts as a continuous-time anti-aliasing filter, achieving SOTA convergence with a fraction of the computational overhead.

## 2. The Three Pillars of Mathematical Novelty (Methodology Section)
*This is where you win the reviewers over. You must explicitly highlight these three innovations.*

### Novelty A: Edge-Deployable DFST Physics (Bypassing ASTRA)
*   **What we did:** Replaced standard ASTRA/Ray-Tracing system matrices with the Differentiable Fourier Slice Theorem (DFST) using 100% native PyTorch (`torch.fft`, `grid_sample`).
*   **Q1 Justification:** Classical ray-tracing is $O(N^3)$ and requires heavy C++ backends, making SOTA models impossible to run on mobile NPUs or hospital edge devices. DFST reduces this to $O(N^2 \log N)$. 
*   **The "Magic":** Historically, DFST fails due to severe polar-to-Cartesian "gridding artifacts" (star-like noise). We propose that the unrolled KINN architecture acts as an *adaptive, continuous-time anti-aliasing filter*, mathematically curing the historical flaw of Fourier-based CT.

### Novelty B: The Kirchhoff ODE Discretization (Lipschitz Stability)
*   **What we did:** Modeled the unrolled feature map updates as an electrical RC circuit governed by Kirchhoff’s Current Law: $C \frac{dV}{dt} + GV = I$.
*   **Q1 Justification:** Standard CNNs and Transformers in unrolled networks have no physical bounds; if the physical gradient (current $I$) spikes, the network explodes. We solved this ODE using exact Zero-Order-Hold (ZOH) discretization: $V_{t+1} = V_t \exp(-G/C) + \dots$
*   **The "Magic":** Because $\exp(-G/C)$ is strictly bounded between $(0, 1)$, the network is unconditionally stable and Lipschitz continuous. Exploding gradients are mathematically impossible.

### Novelty C: Stateful Dynamical Memory
*   **What we did:** Passed the "Voltage State" ($V_t$) from one unrolled cascade to the next.
*   **Q1 Justification:** Existing models (like PAUM or LPD) treat each cascade independently—they only pass the reconstructed image forward, losing high-dimensional feature depth. PI-KINN is a true recurrent dynamical system, allowing it to remember complex artifact geometries across the entire proximal gradient loop.
